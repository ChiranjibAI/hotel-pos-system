# Privacy Policy

**Last updated: July 25, 2026**

Hotel POS System is built with privacy as a core principle. This policy explains what data we collect (almost nothing) and how it is handled.

## Data Collection

**Hotel POS System does not collect any personal data.**

The app is fully offline. It does not:
- Connect to the internet or any remote server
- Send, upload, or transmit any data off your device
- Use analytics, tracking, or advertising SDKs
- Collect device identifiers, location, or usage statistics
- Require an account or login

## Data Storage

All data you enter — menu items, orders, inventory, tables, settings, backups — is stored locally on your device's internal storage. Data is never transmitted off the device.

- **Order data**: stored in a local SQLite/Sembast database on your device
- **Automatic backups**: JSON files written to your device's documents folder every 12 hours
- **Manual exports**: only created when you explicitly export (CSV/Excel/Google Sheets)

## Permissions Used

- **Bluetooth**: used only to connect to receipt printers you explicitly pair. No Bluetooth data is transmitted off-device.
- **Storage**: used to store your database and backups locally. No data is shared.
- **Nearby devices** (Android 12+): required for Bluetooth printer pairing.

No camera, microphone, location, contacts, or phone-state permissions are requested.

## Data Deletion

Uninstalling the app removes all data immediately. You can also clear data from your device's Settings > Apps > Hotel POS System > Storage > Clear Data.

## Children's Privacy

This app is intended for business use by restaurant owners and staff. It is not directed at children and does not knowingly collect any data from children.

## Third-Party Services

This app does not use any third-party analytics, advertising, or cloud services. The source code is open for audit.

## Changes to This Policy

Any changes will be posted in the app and in this document. Because the app is offline, this policy will not change without an app update.

## Contact

For questions about this privacy policy, contact: support@hotelpos.system

## Open Source

Hotel POS System is open-source software. The source code is available for audit, which means you can verify the privacy claims in this policy by reading the code yourself.
